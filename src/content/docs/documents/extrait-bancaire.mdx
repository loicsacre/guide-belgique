## Ce que dit chaque ligne

<Legend>
<li>**Salaire** : le net de la [fiche de paie](../fiche-de-paie/), versé fin de mois pour le mois écoulé. → [[salaire-net]]</li>
<li>**Ordre permanent le lendemain du salaire** : l'épargne part avant d'être vue ; c'est la méthode la plus efficace pour la réserve. → [[epargne-de-precaution]]</li>
<li>**Loyer avec communication structurée** : à toi de pousser le paiement (ordre permanent) ; le bailleur ne prélève pas. → [[domiciliation-ordre-permanent]]</li>
<li>**Domiciliation énergie** : le fournisseur prélève le montant qu'il a fixé ; révisable après le décompte annuel. → [[energie]]</li>
<li>**Paiements par carte de débit** : ton argent, débité immédiatement. → [[compte-a-vue]]</li>
<li>**Communication structurée +++ … +++** : obligatoire pour tout paiement à l'État : elle identifie le dossier ; sans elle, le paiement n'est pas attribué. → [[domiciliation-ordre-permanent]]</li>
<li>**Carte de crédit** : toutes les dépenses du mois précédent prélevées en une fois. Remboursement intégral = pas d'intérêts ; partiel = crédit à 12-15 %. → [[credit-consommation]]</li>
<li>**Paiement à un commerçant inconnu** : vérifie chaque mois les lignes que tu ne reconnais pas ; contestation possible auprès de la banque. → [[fraude-phishing]]</li>
<li>**Frais de compte** : de 0 à ≈ 5 €/mois ; comparables. → [[compte-a-vue]]</li>
<li>**Solde final** : ce mois dégage ≈ 400 € après l'épargne. Mais mars n'a ni assurance annuelle, ni régularisation d'énergie, ni taxe : les dépenses annuelles doivent être provisionnées. → [[budget]]</li>
</Legend>

## Ce qu'un budget tire de cet extrait

| Catégorie | Montant | Part du net |
| --- | ---: | ---: |
| Logement (loyer, énergie, assurance, télécom) | 1 008,50 € | 41 % |
| Épargne | 250,00 € | 10 % |
| Alimentation, santé, transports, loisirs | ≈ 795 € | 33 % |
| Reste | ≈ 386 € | 16 % |

Le loyer seul représente 33 % du net : la limite habituelle. Voir [[budget]] et l'[outil budget](../../outils/budget/).
