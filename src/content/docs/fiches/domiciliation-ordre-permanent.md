## En langage simple

Le mot « domiciliation » désigne en Belgique deux choses sans rapport : ton inscription à la commune ([[domicile]]) et le **prélèvement bancaire automatique**. Ici, on parle du second.

## Les deux mécanismes

| | Ordre permanent | Domiciliation (mandat SEPA) |
| --- | --- | --- |
| Qui déclenche ? | **Toi** : ta banque envoie | **Le créancier** : il prélève |
| Montant | **Fixe**, décidé par toi | **Variable**, décidé par le créancier (sa facture) |
| Usage | Loyer, épargne, pension alimentaire | Énergie, télécom, assurances, abonnements, impôts (via MyMinfin) |
| Arrêter | Tu le supprimes dans ton app, effet immédiat | Tu révoques le mandat chez ta banque **et** préviens le créancier (sinon il te réclame autrement) |
| Si le compte est vide | Le virement ne part pas (retard de loyer…) | Le prélèvement est rejeté, frais possibles des deux côtés |

## Le droit au remboursement

Pour une domiciliation européenne (SEPA Core), tu peux demander à ta banque le **remboursement d'un prélèvement dans les 8 semaines**, sans justification. Pour un prélèvement sans mandat valable, le délai monte à 13 mois. Cela ne supprime pas la dette : le créancier peut la réclamer autrement, mais ça te protège contre une facture contestée prélevée trop vite.

## Ce que ça change pour toi

- Les domiciliations rendent le [[budget]] **lisible** : tes charges fixes partent toutes seules, à condition de les lister une fois par an (abonnements oubliés !).
- Prévois les prélèvements **irréguliers** (acompte énergie révisé, régularisation annuelle) : voir [[energie]].
- Pour l'épargne, l'**ordre permanent** vers le [[compte-epargne]] le lendemain du salaire est la méthode la plus efficace. Voir [[epargne-de-precaution]].
- En cas de changement de banque, le **service de mobilité bancaire** transfère domiciliations et ordres permanents gratuitement.
