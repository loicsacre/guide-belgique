## En langage simple

Un salarié est imposé sur son salaire moins un forfait. Un indépendant est imposé sur son **bénéfice** : ce qu'il encaisse **moins ce que l'activité lui coûte**. Chaque euro de frais justifié réduit la base de l'impôt (jusqu'à 50 % + additionnels) **et** des cotisations sociales (20,5 %). D'où l'obsession des indépendants pour « passer en frais ». Mais un frais reste un euro dépensé : il « coûte » toujours 30 à 40 centimes.

## Les trois conditions

1. Lié à l'**activité professionnelle** (pour acquérir ou conserver des revenus).
2. **Payé ou supporté** pendant l'année (ou amorti).
3. **Justifié** par une pièce (facture au nom de l'entreprise, ticket, contrat).

## Entièrement, partiellement, pas du tout

| Frais | Déductibilité (règle générale) |
| --- | --- |
| Matériel, logiciels, fournitures, comptable, assurances pro, formations, cotisations sociales, PLCI | **100 %** |
| Loyer ou part du logement utilisée comme bureau | Au prorata de la surface professionnelle (**quote-part**) |
| Télécom, internet, énergie à usage mixte | Quote-part professionnelle (souvent 50 à 80 %) |
| **Voiture** | Selon les émissions de CO₂ et la date d'achat : les thermiques descendent vers 0 % de déductibilité d'ici 2028 (achat après mi-2023), les électriques restent à 100 % puis dégressif ; carburant idem ; TVA max 50 % |
| **Restaurant** | 69 % (TVA non récupérable) |
| Cadeaux d'affaires | 50 % |
| Vêtements | 0 % sauf vêtements de travail spécifiques |
| Amendes | 0 % |
| Investissements durables (ordinateur, mobilier, véhicule) | Pas en une fois : par **amortissement** sur leur durée de vie. Voir [[amortissement-comptable]] |

## Exemple (fictif)

| | |
| --- | ---: |
| Chiffre d'affaires HTVA | 70 000 € |
| Frais 100 % (matériel, comptable, assurances, formations) | − 6 000 € |
| Bureau à domicile (20 % de 12 000 € de loyer + énergie) | − 2 400 € |
| Voiture (quote-part 70 %, déductibilité 50 %) | − 1 600 € |
| **Bénéfice avant cotisations** | **60 000 €** |

## Ce que ça change pour toi

- Garde **toutes** les pièces 7 ans ; sans justificatif, pas de déduction en cas de contrôle.
- Un **compte professionnel séparé** simplifie tout.
- Les frais mixtes se **défendent** : documente la clé de répartition (plan du bureau, carnet de route).
- Le même mot désigne, pour les **salariés**, le forfait ou les frais réels : voir [[revenu-imposable]].
