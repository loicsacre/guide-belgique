## En langage simple

Pour l'administration en ligne, tu as besoin de **prouver ton identité**. Deux moyens : ta **carte eID** (avec un lecteur de carte et ton code PIN) ou l'application **itsme** sur ton téléphone. Les deux passent par **CSAM**, le système fédéral de connexion, qui donne accès à tous les portails publics avec le même compte.

## Les portails qui comptent

| Portail | Ce que tu y fais |
| --- | --- |
| **MyMinfin** (Tax-on-web) | [[declaration-fiscale]], [[avertissement-extrait-de-role\|AER]], précompte immobilier, numéro de compte pour les remboursements, titres de propriété (cadastre) |
| **MyPension** | Carrière enregistrée, estimation de ta [[pension]], épargne-pension complémentaire |
| **MySocialSecurity** | Droits sociaux, attestations |
| **My eBox** | Boîte aux lettres officielle : AER, courriers de la mutualité, du SFP, de la commune… |
| **Mon dossier** (Registre national) | Composition de ménage, certificats de domicile |
| **Ma santé** | Dossier médical partagé |

## Ce que ça change pour toi

1. **Active itsme** une fois (avec ta carte eID ou via ta banque) : tu l'utiliseras aussi pour la banque, l'assureur, le secrétariat social.
2. **Active ton eBox** et surveille-la : une fois activée, certains organismes **cessent d'envoyer du papier**. Une AER ignorée dans l'eBox, c'est un délai de paiement qui court.
3. Vérifie dans MyMinfin le **numéro de compte** connu du SPF Finances avant chaque remboursement.

:::caution[Sécurité]
Les administrations ne te demanderont jamais ton code itsme ni tes codes bancaires par SMS, e-mail ou téléphone. Voir [[fraude-phishing]].
:::

## À ne pas confondre

| Terme | Ce que c'est |
| --- | --- |
| eID | La carte physique + son code PIN. |
| itsme | L'application privée (créée par les banques et opérateurs), reconnue par l'État. |
| CSAM | Le guichet de connexion fédéral derrière les portails. |
| eBox | La boîte aux lettres, pas un portail de démarches. |
