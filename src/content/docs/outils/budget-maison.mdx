La mensualité du crédit n'est que la moitié de l'histoire. Une maison coûte aussi des taxes, des assurances, de l'énergie, et surtout une **provision** pour ce qui devra être remplacé un jour : 🟠 1 à 2 % de sa valeur de reconstruction par an selon les gestionnaires immobiliers. Ce simulateur additionne tout pour obtenir un coût mensuel comparable à un loyer.

<Tool />

## Repères

- La **valeur de reconstruction** (base de l'[[assurance-habitation]]) n'est pas le prix d'achat : elle exclut le terrain.
- Le **précompte immobilier** est une taxe annuelle sur le revenu cadastral indexé ([[precompte-immobilier]]).
- Les consommations se lisent sur le décompte annuel ([Lire une facture d'énergie](../../documents/facture-energie/)) ; l'[[energie]] explique la structure des prix.
- La provision se place sur un compte distinct de l'[[epargne-de-precaution]] ; le calendrier des entretiens est dans [[entretien-maison]].
- Pour la comparaison avec un loyer sur le long terme : [Louer ou acheter](../louer-ou-acheter/) et [[louer-vs-acheter]].
